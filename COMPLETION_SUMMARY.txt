================================================================================
REAL ACADEMIC FORMULAS IMPLEMENTED
================================================================================

CO Attainment (Course Outcome)
  Formula: Sum(marks for CO questions) / Sum(total marks for CO) * 100
  Implementation:
    - Queries question_co_mapping_table
    - Aggregates student_marks
    - Calculates percentage across all students
    - Persists in co_attainments table
    - Returns level (L3/L2/L1)

PO Attainment (Program Outcome)
  Formula: Average of mapped CO attainments for this course
  Implementation:
    - Queries co_po_mapping_table
    - Retrieves all mapped CO attainments
    - Calculates average
    - Returns level (L3/L2/L1)

PSO Attainment (Program Specific Outcome)
  Formula: Average of mapped CO attainments for this course
  Implementation:
    - Queries co_pso_mapping_table
    - Same calculation as PO
    - Returns level (L3/L2/L1)

Attainment Levels
  Level 3: ≥ 70% (Fully Attained)
  Level 2: 60-69% (Partially Attained)
  Level 1: < 60% (Minimally Attained)
